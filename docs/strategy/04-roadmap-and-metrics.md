# 04. 로드맵과 지표

기준일: 2026-11-14 · 상위 문서: [전환 전략](README.md)

기간 추정은 두지 않는다(0.2까지의 원칙 유지). 각 릴리스의 완료 기준을 통과하면 다음으로 넘어간다. 게이트(G0~G3)는 [03. 규제·리스크](03-compliance-and-risk.md) 1절 정의를 따른다.

## 1. 릴리스 순서

| 릴리스 | 이름 | 핵심 산출물 | 게이트 | 완료 기준 |
| --- | --- | --- | --- | --- |
| 0.3 | 규칙 엔진과 시뮬레이션 체결 | 규칙 명세 v1, 서버 규칙 엔진(고정·일일 리셋·최소 거래일), 시세 수집 1종, 시장가·지정가·손절·익절 체결, 거래 계정 모델 | — | 규칙 명세의 모든 예시가 엔진·화면에서 같은 센트 결과. 시세 단절 시 체결 보류 동작 확인 |

| 0.7 | 펀딩과 보상 지급 | 본인확인, 지급 요청·심사·송금, 지급 준비금, 부정거래 점수 v1 | **G2** | 모의 지급 20건 원장 대사 일치. 준비금 초과 시 승급 중단 동작 확인 |

| B1 | 화이트라벨 파일럿 | 멀티테넌시, 테넌트별 규칙·브랜딩, 업체 관리 콘솔 | **G3** | 파일럿 1곳 운영 30일 |

0.2의 백로그 작업 2(학습 예시)·3(복기)은 0.4의 아카데미와 대시보드 복기 화면으로 흡수한다. 작업 5(수동 거래일 리셋)는 0.3 규칙 엔진의 자동 일일 리셋으로 대체한다.

게임 레이어(트랙 레이스, [05](05-game-layer.md))는 **보류**다. 2026-11-23에 우선순위를 런칭(유료 평가·수익 경로)으로 되돌렸고, 05의 R0~R5는 위 릴리스 순서에 들어 있지 않으며 착수 일정도 없다. R0에서 만든 트랙 추출·재생 도구(`data`의 `npm run track:extract`, `backend`의 `npm run dev:sim -- --track`)는 고정 호가 구간을 그대로 재생해 체결·한도 판정의 회귀 테스트와 디버깅에 쓸모가 있어 되돌리지 않고 남겨 둔다. 재개 조건은 유료 평가(G1)가 돌아가고도 남는 유입·리텐션 문제가 실측으로 확인될 때다.

## 3. 지표

### 북극성 지표

**규칙을 이해하고 지킨 거래 계정 수**: 기간 내 최소 거래일을 채우고 위반 없이 기간을 마친(또는 목표를 달성한) 계정 수. 매출이 아니라 이 지표를 북극성으로 두는 이유는, 통과율이 낮을수록 매출이 늘어나는 유인과 반대 방향의 목표를 조직에 두기 위함이다.

### 단계별 지표

| 영역 | 지표 | 0.4 목표(가설) |
| --- | --- | --- |
| 유입 | 아카데미 → 시즌 참가 전환율 | 15% |
| 활성 | 시즌 참가자 중 최소 거래일 달성 비율 | 50% |
| 이해 | 위반 종료 계정 중 "위반 직전 경고를 받았던" 비율 | 90% 이상(경고 누락 탐지 지표) |
| 신뢰 | 판정 이의 제기 중 오판 인정 비율 | 0%에 수렴, 발생 시 원인 분석 의무 |
| 품질 | 시세 단절로 체결 보류된 시간 비율 | 0.1% 미만 |
| 사업(0.6~) | 구매→1단계 통과→펀딩→첫 지급 전환율 | 시즌 데이터로 재추정 |
| 재무(0.7~) | 미지급 보상 추정액 / 지급 준비금 | 항상 1 미만 |
