# Oh My Prop

프랍 트레이딩의 손실 한도와 거래 기록을 연습하는 한국어 학습용 시뮬레이터. 가상의 고정 기준 규칙과 사용자가 입력한 수치만 사용합니다. 실제 업체의 판정, 거래 조언, 실시간 위험 관리 도구가 아닙니다.

## 실행

```sh
cd frontend # 이미 저장소 안이라면 생략
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 별도의 의존성 설치가 필요하지 않습니다. 계산기 입력은 저장되지 않지만, 가상 거래 연습장 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 선택 기능인 계정 동기화는 같은 출처에서 백엔드가 함께 서빙될 때만 동작하며, 정적 서버로만 열면 동기화 패널이 사용 불가로 표시되고 나머지 기능은 그대로 동작합니다.

계정 동기화까지 함께 쓰려면 형제 저장소 `oh-my-prop/backend`를 받아 함께 실행합니다. 백엔드가 API와 이 화면을 같은 출처로 제공합니다.

```sh
cd ../backend
npm start   # http://127.0.0.1:8787
```

## 학습 모델

- 일일 한도선 = 일일 시작 에쿼티 − 초기 잔고 × 일일 손실 한도(%).
- 최대 한도선 = 초기 잔고 − 초기 잔고 × 최대 손실 한도(%).
- 각 잔여 금액 = 현재 에쿼티 − 해당 한도선. 두 잔여 금액 중 작은 쪽이 이 가상 모델의 더 가까운 한도입니다.
- 소수 센트가 생긴 한도선은 보수적으로 올림합니다. 한도선에 도달하거나 그 아래인 경우 위반 가능성으로 표시합니다.

에쿼티에는 평가손익이 반영될 수 있습니다. 수수료·스왑 등 포함 여부는 실제 계좌 자료에 따라 다릅니다. 이 모델은 고정된 최대 손실 기준과 직접 입력한 일일 시작 에쿼티를 가정합니다. 자동 일일 리셋, 추적형 손실, 업체별 규칙과 실시간 시세는 지원하지 않습니다. 실제 사용 전에는 해당 업체의 최신 공식 규정과 계좌 상태를 직접 확인해야 합니다.

### 리셋 전후 비교

[FTMO CFD 2-Step 공개 규칙](https://ftmo.com/en/trading-objectives/)을 참고한 별도의 교육용 시나리오입니다. 초기 가상 자본의 5%를 리셋 시점의 **잔고**에서 빼 일일 한도선을 구하고, 최대 한도선은 초기 자본의 90%로 고정합니다. 전후 리셋 잔고는 직접 입력하며 비교용 에쿼티는 동일하게 유지합니다. 기본 예시에서 한도선이 $95,000에서 $97,000으로 올라가면 에쿼티 $96,000은 그대로여도 새 한도 아래가 됩니다.

리셋 시각과 계좌 이력은 계산하지 않고 입력된 두 스냅샷만 비교합니다. 소수 센트 한도선은 위쪽 센트로 올립니다. 한도와 정확히 같은 경우와 아래인 경우를 구분하지만, 업체의 공식 위반 판정은 아닙니다. 스왑·수수료의 개별 계산, 시점 사이에 발생한 손실, 다른 평가 조건은 포함하지 않습니다.

### 가상 거래 연습장

첫 화면의 링크 또는 `/journal.html`에서 가상 세션의 초기 잔고와 손실 허용률을 정하고, 청산한 가상 거래의 순손익을 차례로 입력합니다. 한도선 도달 이력은 이후 손익이 회복되더라도 유지됩니다. 거래를 삭제하면 남은 거래를 처음부터 다시 계산하므로 이력도 바뀔 수 있습니다.

세션 설정은 입력 중인 초안과 적용된 값을 구분합니다. **설정 적용**을 눌러야 검증·전체 재계산·저장이 일어나고, 거래가 있으면 모든 과거 잔고와 도달 이력을 다시 계산한다는 확인을 받습니다. **변경 취소**는 마지막 적용값을 복원합니다. 적용하지 않은 변경이 있는 동안에는 거래 추가·삭제, 전체 삭제, 백업 가져오기, 서버 동기화를 막고 적용 또는 취소를 안내합니다. 전체 삭제는 삭제할 거래 수와 되돌릴 수 없다는 설명을 확인한 뒤 실행하며 설정은 유지합니다.

저장 상태는 **저장됨**, **이 화면에만 있음(미저장)**, **기존 데이터 읽기 불가** 세 가지로 항상 표시합니다. 저장에 실패하면 화면의 세션을 유지한 채 **저장 다시 시도** 버튼과 백업을 제공하고, 읽을 수 없는 원본은 재시도·가져오기·불러오기 어느 경로로도 덮어쓰지 않습니다.

가상의 단일 세션만 지원하며 미실현 손익, 시세, 실제 주문, 일일 리셋 및 업체별 규칙은 반영하지 않습니다. 수수료 등은 직접 순손익에 포함해야 합니다. 민감한 실제 계좌 정보는 입력하지 마세요.

연습장의 **JSON 백업 다운로드**로 마지막에 적용한 세션을 파일로 보관하고, **JSON 백업 가져오기**로 복원할 수 있습니다. 가져오기는 파일을 검증하고 확인을 받은 뒤 로컬 저장에 성공해야 기존 설정과 거래를 대체하며, 아직 저장되지 않은 내용도 함께 대체됩니다. 최대 크기는 1 MiB이며, 취소하거나 검증·저장에 실패하면 현재 세션을 유지합니다.

백업 파일은 암호화되지 않으며 세션과 거래 이름이 포함됩니다. 안전하게 보관하고 민감한 정보를 입력하지 마세요.

### 계정 동기화 (선택)

백엔드를 같은 출처에서 함께 서빙하면 연습장의 **계정 동기화** 패널에서 이메일·비밀번호로 가입·로그인하고 세션을 **서버에 저장**하거나 **서버에서 불러오기** 할 수 있습니다. 서버에 저장하면 기록이 서버 데이터베이스에 남으므로 민감한 정보를 입력하지 마세요. 불러오기는 확인을 받고 로컬 저장에 성공한 뒤에만 화면을 교체합니다. 서버 기록이 그사이 바뀌면 충돌을 알리고 서버 기록 보기·서버 내용 사용·내 기록으로 덮어쓰기·취소 중에서 선택할 수 있습니다.
