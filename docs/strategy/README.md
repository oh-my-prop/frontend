# Oh My Prop — 프랍 트레이딩 서비스 전환 전략

기준일: 2026-11-14 · 상태: 전략 초안(결정 대기 항목 포함) · 범위: 조직 전체(`frontend`·`backend`·`data`·`infra`)

0.2까지의 Oh My Prop은 "손실 한도를 배우는 학습용 시뮬레이터"였다. 이 문서 묶음은 제품을 **트레이더를 평가하고 성과에 따라 보상하는 프랍 트레이딩 서비스**로 전환하기 위한 전략과 실행 순서를 정의한다. 기존 [제품 기획서](../../PRODUCT-PLAN.md)의 학습 범위 결정(1절, 7절 "실운용은 범위 밖")은 이 전략으로 대체하며, 대체 시점과 조건은 각 문서에 명시한다.

## 한 줄 결론

> **규칙 엔진과 시뮬레이션 체결을 먼저 만들고, 돈이 오가는 기능(유료 평가·보상 지급)은 법률 의견서라는 게이트를 통과한 뒤에만 켠다.** 그 전까지는 무료 시즌 챌린지로 제품과 데이터를 검증하고, 같은 스택을 기존 프랍 업체에 화이트라벨로 판매하는 B2B 경로를 병행 준비한다.

## 이 전략이 유지하는 0.2의 원칙

1. **금액은 정수 센트로 계산한다.** 손실 한도 경계 판정에 부동소수점을 쓰지 않는다(`src/risk.js`의 방식 유지).
2. **계산 결과보다 원천 이벤트를 저장한다.** 한도선·잔고는 이벤트에서 재계산 가능해야 한다. 판정 기록은 별도 감사 로그로 남긴다.
3. **사용자가 오해할 수 있는 상태를 만들지 않는다.** "시뮬레이션인지 실계좌인지", "보상이 확정인지 심사 중인지"를 화면에 항상 구분해 표시한다.
