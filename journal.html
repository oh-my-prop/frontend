가상 거래 연습장

하나의 가상 세션에서 종료된 거래를 순서대로 기록하고 고정 손실 경계까지의 거리를 살펴보세요.

시뮬레이션 전용입니다. 실제 거래, 거래 실행 또는 특정 업체의 규정 판정이 아닙니다. 시세와 수수료는 자동 반영되지 않으므로 모든 비용을 순손익에 직접 포함하세요. 미실현 손익과 일일 리셋은 계산하지 않습니다.

세션 기록은 이 브라우저의 로컬 저장소에 저장됩니다. 별도로 백업하지 않으면 브라우저 데이터 삭제나 기기 변경 등으로 사라질 수 있습니다. 민감한 정보를 입력하지 마세요.

JSON 백업 및 복원

다운로드한 JSON에는 세션 설정과 거래 기록 등 민감한 데이터가 포함될 수 있으니 안전하게 보관하세요. 파일은 클라우드에 저장되거나 전송되지 않습니다.

내보내기는 마지막으로 적용한 세션만 내보냅니다. 적용하지 않은 설정은 파일에 포함되지 않습니다.

가져오기를 확인하면 현재 세션의 모든 설정과 거래가 파일의 내용으로 대체됩니다. 아직 저장되지 않은 내용도 함께 대체됩니다.

계정 동기화 (선택)

서버에 저장하면 세션 설정과 거래 기록이 서버 데이터베이스에 보관되어 다른 기기에서도 불러올 수 있습니다. 이름·계좌번호 등 민감한 정보는 입력하지 마세요.

계정 상태를 확인하는 중입니다.

비밀번호는 10~200자로 입력하세요. 다른 곳에서 쓰는 비밀번호를 재사용하지 마세요.

01 / SESSION
가상 세션 설정

          
손실 허용액은 초기 잔고의 고정 비율입니다. 경계는 센트 단위로 올림합니다.

          

            
            
            
초기 잔고는 0 초과, 비율은 0 초과 100 이하로 입력하세요. 금액은 소수 둘째 자리까지 가능합니다. 입력은 초안이며 설정 적용을 눌러야 계산과 저장에 반영됩니다.

            

              
              
            

          

          

          

          

          
종료된 거래 추가

          
입력 순서대로 계산합니다. 수익은 양수, 손실은 음수로 입력하세요.

          

            
            
            
모든 비용을 포함한 종료 거래의 순손익을 직접 입력하세요.
